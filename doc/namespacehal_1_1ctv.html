Detailed Description

Everything the clock tree viewer works out from a clock tree before anything is drawn: where the gates are, how they are connected and how large the drawing is. It does not depend on Qt, so it can be tested without a GUI.

Place the gates of a clock tree at their coordinates.

The coordinates of a gate are its location in the layout, unless the keys of both coordinates are given: then they are read from the gate parameters of these names, e.g., from Verilog instance parameters, which unlike a location can be negative. Nets have no coordinates; the only nets in a clock tree are the global inputs at its roots, which are not drawn.

Parameters
[in]tree- The clock tree.
[in]x_key- The name of the parameter that holds the x-coordinate, or std::nullopt to use the location.
[in]y_key- The name of the parameter that holds the y-coordinate, or std::nullopt to use the location.
Returns
The layout on success. An error if only one key is given, the clock tree has no gates or none of them has coordinates. Gates that are only missing some of the coordinates are listed in the layout instead.

Settle the sizes of the drawing.

Every size the user did not provide is derived from the length of a typical connection, the median over all connections of the layout: with a typical connection of 25 units, a node has a radius of 1 unit, a line is 0.5 units wide, a picture has a margin of 20 units and 2 pixels per unit. For a layout without connections, a tenth of its extent takes the place of the typical connection.

The resolution is not limited here: only the scene knows how large the drawing really is, including the width of its lines, so it lowers a derived resolution itself when a picture would be too large.

Parameters
[in]layout- The layout that is drawn.
[in]overrides- The sizes provided by the user.
Returns
The sizes on success, an error if a provided size is not a number or out of range.
