Write a clock tree to a DOT file.

Gates get the coordinates of their location in the layout, unless the keys of both coordinates are given: then they are read from the gate parameters of these names, e.g., from Verilog instance parameters, which unlike a location can be negative.

Parameters
[in]clock_tree- The clock tree.
[in]pathname- The path of the file to write.
[in]x_key- The name of the parameter that holds the x-coordinate, or std::nullopt to use the location.
[in]y_key- The name of the parameter that holds the y-coordinate, or std::nullopt to use the location.
Returns
OK() on success, an error otherwise.

Read a coordinate from a gate parameter, e.g., a Verilog instance parameter.

The parameter must hold a finite number and nothing else apart from surrounding white space, e.g., "-600", "12.5" or "0x10", which is how HAL stores bit vectors.

Parameters
[in]gate- The gate.
[in]name- The name of the parameter.
Returns
The coordinate, or std::nullopt if the parameter is missing or holds no number.

◆ recover_branches()

Result< std::vector< Branch > > hal::cte::recover_branches ( const ClockTree &  clock_tree)

Recover all branches of a clock tree.

Runs a depth-first search from every root and collects each root-to-sink path. A sink is a vertex without successors. Vertices reachable over several paths show up in several branches.

Parameters
[in]clock_tree- The clock tree.
Returns
The branches, each ordered from root to sink, or an error.
