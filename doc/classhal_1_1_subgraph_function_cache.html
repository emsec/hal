Detailed Description

A reusable store for the Boolean functions that SubgraphNetlistDecorator::get_subgraph_function computes and the inputs that SubgraphNetlistDecorator::get_subgraph_function_inputs determines for the output pins of the gates of one specific subgraph.

The subgraph a cache belongs to is sealed in when it is created with SubgraphNetlistDecorator::make_subgraph_function_cache, and the cache can only ever be used for exactly that subgraph.

The cache belongs to the netlist it was created for and must be dropped when the netlist is modified, as its entries are not invalidated by netlist events.
