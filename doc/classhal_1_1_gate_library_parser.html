void hal::GateLibraryParser::request_upgrade ( )
static

Allow the next parse to upgrade a gate library file in an outdated format.

The upgrade replaces the file, so it must only be requested with the consent of the user. The request applies to the next parse only and is withdrawn once that parse is done.
