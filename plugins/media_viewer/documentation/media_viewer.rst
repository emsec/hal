Media Viewer
============

The Media Viewer plugin plays local video files (mp4, m4v, mov) inside HAL.
It is intended primarily for tutorial videos that complement netlist analysis.

Usage
-----

Open the Media Viewer from the HAL plugins menu. Click "Open media file"
on the toolbar to load a video. Use the toolbar to control playback
speed, volume, and seek position. Keyboard shortcuts (Space, M, Up/Down)
work while the player has keyboard focus.
